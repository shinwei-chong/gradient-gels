# Thermophoretic fabrication of stiffness gradient hydrogels  
A collection of MATLAB script files for image analyses originally developed and used for the PhD thesis: "Thermophoretic fabrication of gradient hydrogels for mechanobiology applications".    

Thesis submitted (June 2025) by Shin Wei Chong to the School of Biomedical Engineering, The University of Sydney.

## File description  
1. **fluo_temp_meas.m**: process and analyse fluorescence micrscopy images of temperature-sensitive rhodamineB dye for spatially resolved temperature characterisation (see details in Chapter 4).
    
2. **thermophoresis_exp.m**: process time-lapse images from thermophoresis experiments and visualise change in intensity profile over time (see details in Chapter 4).
     
3. **fluo_stiff_meas.m**: process and analyse fluorescence microscopy images of FITC-labeled gradient hydrogels for spatially resolved stiffness characterisation (see details in Chapter 7).
